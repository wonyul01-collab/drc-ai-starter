# 업무 자동화 개발 표준 (디알컴퍼니)

회사에서 실제로 만든 것: 통합 실적센터(8개 사이트 자료를 매일 06:00·09:30 자동 수집 → 엑셀·메일·웹 화면), 복지용구 현황판(공단 원본 68개월 자동 판독·공지 매일 수집), 복지용구사업소 운영판(로그인되는 점검 사이트), 생산 계획·자금·현황판(엑셀 공유를 화면 입력·승인으로 대체).

## 0. 시작 전 3줄 확인 (사람에게 먼저 보여 준다)
- 지금 손으로 하는 순서(어디 로그인 → 무엇을 받음 → 어떻게 합침 → 누구에게 보냄)
- 끝 모습: 화면 / 엑셀 / 메일 / 알림 중 무엇, 누가 보는지
- 언제 돌아야 하는지(매일 몇 시, 몇 번)

## 1. 수집 — 이 순서로 고른다
1. **공식 API**가 있으면 API(예: 네이버 검색광고 API, 이카운트 Open API).
2. 사이트에 **엑셀 내려받기** 버튼이 있으면 그 버튼을 자동으로 누른다.
3. 둘 다 없으면 **Playwright**(브라우저 자동 조작). 버전은 `playwright==1.60.0` 고정.
- 고정 시간 기다리기(sleep 10초) 금지 → 요소가 나타날 때까지 기다리고, 값을 되읽어 확인, 3회 재시도, 실패 시 화면 캡처와 HTML을 `debug/`에 저장.
- 사이트에 안내창(비밀번호 변경 권유 등)이 뜨면 닫는 단계를 넣는다. 안내창 하나로 수집이 며칠씩 멈춘 사례가 있다.
- 동시 접속 1명 제한 사이트는 로그인하면 쓰던 직원이 튕긴다. 시험은 내려받기 없이(`--skip-download`).
- 2단계 인증 사이트는 로그인 상태를 저장한 브라우저 프로필을 쓴다(`profiles/`, 깃허브 제외).

## 2. 검증 — 반드시
- 원본의 합계 줄(「계」·엑셀 합계)과 계산 결과를 대조. 다르면 반영하지 않는다.
- 같은 거래가 두 곳에서 들어오는지(이중 집계) 확인. 예: 이카운트에 쿠팡 출고가 거래처로 들어와 560만 원이 두 번 잡혔다.
- 오래된 파일이 최신 값을 덮지 않게 수집 시각을 기록.
- 광고 매출은 실제 구매 금액 칸을 쓴다(네이버 `purchaseConvAmt`, `convAmt`는 부풀려짐).

## 3. 계산·화면
- 계산 코드는 한 곳(파이썬). 화면·메일·엑셀이 같은 함수를 부른다.
- 화면은 스킬 '화면기준'을 따른다. 수치는 그래프, 설명은 표.
- 권한이 다른 사람이 보면 아이디별 보기 권한(예: 손익은 대표만)을 서버에서 막는다.

## 4. 게시 (Vercel)
- `vercel@65.0.0` 고정(최신판 설치 오류 이력). 게시 로그 끝에 완료 문구가 없으면 실패로 본다.
- **같은 주소에 다시 게시**. 새 주소를 만들지 않는다. 보고에 화면 주소를 꼭 적는다.
- 입력·저장이 필요하면 Vercel Blob(비공개)에 저장, 로그인은 쿠키+middleware.
- 브라우저가 옛 화면을 기억하므로 파일 주소에 `?v=수정시각`을 붙인다.

## 5. 자동 실행 (윈도우 작업 스케줄러) — 조용히 실패하는 곳
- 경로에 공백이 있으면 잘린다 → `cmd.exe /c ""경로""` 형태로 등록.
- 노트북은 배터리일 때 안 돈다 → `-AllowStartIfOnBatteries -DontStopIfGoingOnBatteries`.
- 검은 창이 뜨지 않게 `wscript.exe run_hidden.vbs <명령>` 또는 `pythonw`.
- 등록 후 **반드시**: `Get-ScheduledTaskInfo` 의 LastTaskResult = 0, 그리고 결과 파일 수정 시각이 오늘인지 확인. "등록했습니다"로 끝내지 않는다.

## 6. 점검·알림
- 실패하면 종료코드를 0이 아닌 값으로 남기고, 메일/텔레그램으로 "[자료 누락]" 알림.
- 감시는 '파일이 생겼나'가 아니라 '받는 사람에게 전달됐나'까지 본다(메일이 18일 안 나간 사고: 파일만 보고 있었음).
- 메일 535 오류 → 네이버 메일 설정 「POP3/SMTP 사용함」부터 확인.

## 7. 실행 파일·인코딩
- 직원이 더블클릭으로 쓰게 하려면 PyInstaller로 .exe. 켜져 있는 exe는 덮어쓰지 말고 끈 뒤 교체.
- PowerShell 출력이 깨지면 `PYTHONIOENCODING=utf-8`.

## 8. 안전
- 비밀값은 `.env`만. 출력할 때도 값 말고 이름만.
- 고치기 전에 `git commit`. 파일 삭제·발송·결제·공개는 사람 확인 후.

## 9. 끝낼 때 보고 형식
만든 것(주소·폴더) / 이전 수작업 → 지금 / 검증 결과(원본 합계와 일치 여부) / 자동 실행 확인 결과 / 다음에 고칠 점.
