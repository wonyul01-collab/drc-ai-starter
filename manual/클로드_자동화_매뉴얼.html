    처음 자동화할 일 고르기

    좋은 첫 과제나중에 할 과제
    내 PC 안의 엑셀 여러 개를 합쳐 합계 표 만들기로그인·2단계 인증이 있는 사이트 자동 수집
    같은 양식 보고서(주간 실적, 재고표) 자동 작성여러 사람이 입력·승인하는 화면
    폴더에 파일이 들어오면 정리·이름 바꾸기고객 개인정보가 들어간 자료

    고르는 기준 3가지

    1. 일주일에 2번 이상 한다
    2. 매번 순서가 같다
    3. 틀려도 바로 확인할 수 있다(원본과 비교 가능)

    첫 지시 — 그대로 붙여 넣어도 됩니다

    1. 합칠 엑셀 파일을 클로드작업\내_자동화 폴더에 복사(고객 개인정보가 없는 파일로)
    2. PowerShell → cd ~\클로드작업 → claude
    3. 아래 지시를 붙여 넣기
    내_자동화 폴더에 있는 엑셀 파일들을 합쳐서, 채널별·날짜별 합계를 보여 주는 화면을 만들어 줘.
화면은 회사 화면기준 스킬을 따르고, 필요한 프로그램은 알아서 설치해 줘.
시작 전에 무엇을 어떻게 만들지 3줄로 먼저 보여 주고,
끝나면 원본 합계와 화면 합계가 같은지 대조해서 알려 줘.
    클로드가 "이 명령을 실행해도 될까요?"라고 물으면 내용을 읽고 허용합니다. 파일 삭제·발송처럼 되돌릴 수 없는 일이면 멈추고 담당자에게 물어보세요.

    회사 화면 기준

    "만든 자가 불편하면 사용하는 고객이 편안해진다." — 대표. 키트의 스킬 '화면기준'에 들어 있어 클로드가 자동으로 따릅니다.

    지킬 것금지
    왼쪽 = 업무 묶음, 위 탭 = 진행 순서, 한 화면 안에서 처리세로로 길게 내려 읽는 화면
    본문 15px·표 14px·탭 16px 이상, 글꼴 Pretendard13px 이하 본문
    수치는 그래프, 설명은 표문장 줄줄이 나열
    주 버튼은 화면마다 하나둥근 카드+그림자 남발, 알약 단추, 이모지, 보라→파랑 그라디언트, 방사형 빛줄기 무늬

    이 매뉴얼 화면 자체가 그 기준의 예시입니다.

    깃(Git) = 게임의 저장점

    명령을 외울 필요 없습니다. 클로드에게 말로 시킵니다.

    하고 싶은 것클로드에게실제 명령(참고)
    처음 시작"이 폴더 git으로 관리 시작해 줘. .gitignore 확인하고."git init
    저장점"지금 상태 저장점 남겨 줘."git add . && git commit -m "설명"
    바뀐 것 보기"마지막 저장점 이후 뭐가 바뀌었어?"git diff
    되돌리기"마지막 저장점으로 되돌려 줘."git restore .
    .env(비밀번호)·고객 파일·실적 원본은 .gitignore로 저장점에서 빼야 합니다. 키트의 .gitignore가 이미 빼 줍니다.

    깃허브 = 인터넷 저장소

    하고 싶은 것클로드에게
    회사 깃허브에 새 저장소"이 폴더를 회사 깃허브에 비공개 저장소로 올려 줘. 비밀값이 안 올라가는지 먼저 확인하고."
    다른 PC에서 이어서"회사 깃허브의 ○○ 저장소를 받아 줘."
    최신으로 맞추기"깃허브 최신 내용 받아 줘." / "지금 것 올려 줘."
    업무 저장소는 비공개(private)가 기본입니다. 공개 저장소는 이 키트처럼 비밀값이 전혀 없는 것만.

    Vercel = 화면을 인터넷 주소로

    이 화면을 Vercel에 올려서 주소 알려 줘.
로그인이 필요하면 아이디·비밀번호 로그인을 붙이고, 비밀값은 .env에 넣어 줘.
다음부터는 같은 주소에 다시 올려 줘.
    규칙이유
    같은 주소에 다시 올림주소가 바뀌면 동료가 옛 화면을 봄
    Vercel CLI 65.0.0 고정최신판 설치 오류 이력
    게시 기록 끝에 완료 문구 확인없으면 실패한 것
    입력·저장은 Vercel Blob(비공개)동료가 입력한 내용이 모두에게 같이 보임
