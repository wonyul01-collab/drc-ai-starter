# 화면 기준 (어기면 낙제)

> "화면 구성할 때는 좌측에 업무 카테고리를 넣고, 그 카테고리의 업무 진행 절차를 탭 형태로 만들어서 이어서 진행할 수 있게. 한 화면 안에서 확인하고 처리할 수 있도록." — 대표
> "만든 자가 불편하면 사용하는 고객이 편안해진다." — 대표

## 골격
```
┌────────────┬────────────────────────────────────────────┐
│ 프로그램명  │ [절차 탭1] [탭2] [탭3]            상태 요약 │
│ 업무 묶음 A │ 지금 할 일 한 줄 ··············· [다음: 탭2] │
│ 업무 묶음 B │ 가운데: 표·그래프·작업         │ 오른쪽: 도구 │
│ 업무 묶음 C │                               │ [주 버튼 1개]│
└────────────┴────────────────────────────────────────────┘
```
1. 왼쪽 = 업무 묶음, 위 탭 = 고른 업무의 진행 순서, 탭 안 첫 줄 = 지금 할 일 + [다음] 버튼.
2. 1920×1080과 1366×768에서 페이지 세로 스크롤 0. 넘치면 하위 탭·오른쪽 패널로 나눈다.
3. 주 버튼은 화면마다 하나.

## 글씨
- 본문·버튼·입력칸 15px, 표 14px, 탭·카테고리 16px, 주요 값·제목 18~24px, 보조 13px(회색은 진하게).
- 글꼴 Pretendard, 숫자는 고정폭(`font-variant-numeric: tabular-nums`).

## 표현
- 수치는 그래프, 설명은 표. 문장 나열 금지.
- 한국어. 전문어는 쉬운 말. 파일 경로·내부 파일 이름은 화면에 안 보이게.
- 금지: 둥근 카드+그림자 남발, 알약 단추, 이모지, 보라→파랑 그라디언트, 가운데 정렬 일색, 3단 마법사 폼, 방사형 빛줄기·햇살 무늬, 'AI 생성' 표시.
- 고를 것이 있으면 선택지(기본값 미리 선택) + 입력칸 + Enter로 보내기.
- 탭끼리 예시 숫자가 서로 맞아야 한다(한 데이터에서 만든다).

## 완성 전 확인
- 두 크기로 캡처해 스크롤·글씨 크기를 재고, 만든 사람이 아닌 다른 눈(다른 클로드 창)으로 채점받는다.
