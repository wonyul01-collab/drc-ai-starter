# 처음 시작하기

1. PowerShell을 열고 `cd ~\클로드작업` → `claude` 입력.
2. 처음 한 번 회사 계정으로 로그인합니다.
3. 첫 지시 예시(그대로 붙여 넣어도 됩니다):

```
내_자동화 폴더에 있는 엑셀 파일들을 합쳐서, 채널별·날짜별 합계를 보여 주는 화면을 만들어 줘.
화면은 회사 화면기준 스킬을 따르고, 필요한 프로그램은 알아서 설치해 줘.
끝나면 원본 합계와 화면 합계가 같은지 대조해서 알려 줘.
```

4. 결과를 보고 구체적으로 고쳐 달라고 합니다. 예: "3번째 칸 합계가 원본보다 12,000원 많아. 반품 줄을 빼 줘."
5. 끝나면 "오늘 고친 거 CLAUDE.md 배운 것에 저장해 줘"라고 말합니다.
6. 매일 자동으로 돌리고 싶으면: "이거 매일 아침 7시에 자동으로 돌게 작업 스케줄러에 등록하고, 등록 결과까지 확인해 줘."
